    卷一市场适配根治计划（novel-market-overhaul）总设计

    Date: 2026-10-25 | Status: Approved（brainstorming 三节逐节确认） | Severity: 🟥 P0 | 方法: 引擎置换 + 平台章原生粒度（方案 C）+ 八 spec 依次根治 | 系列: 市场适配层（源自 2026-10-25 对 novel-xinghuo-vol1 前九章的两轮全量诊断 + 近三年头部对标） | 依赖: 无 | 范围: outline 三文件 + genre-config + 角色卡数据修复 + pipeline 粒度合同（planning/drafting/拆分器/release_split v2）+ G 系跨章不变量门 + 声口/文体指纹/回触三门 + 重生成验收协议

    2026-10-25 brainstorming 定稿。决策路径：两轮诊断（第一轮：五处跨章硬伤 + 六项结构机制问题 + 头部对标差距；第二轮：情感记忆制度性切除、四代入引擎被大纲主动拆除、卷一规划自身节奏缺陷、文体指纹三组定量、零碎漂移）→ 用户四决策：①双平台（起点粒度生成为主，番茄发布层适配）②旧九章全部丢弃，问题根治后删除重新生成（spec 无迁移包袱）③引擎置换（保留账单/记名/人民史观内核，四引擎换新，非全面市场化、非只调密度）④方案 C：平台章原生生成为主 + 场景簇批量派发（一次派发 2 章）。三节设计（引擎置换细则 / 粒度改革合同 / spec 路线图）逐节确认通过。

    0. 诊断摘要（问题全量清单）

    诊断对象：novel-xinghuo-vol1/chapters/chapter-1..9.md（约 7.7 万字）。25 项问题分七层：

    层 问题
    内容硬伤（5） 人称断裂（ch1 我 / ch2+ 他）；主角称谓漂移 + 与女主「灯」撞名（ch4-5 主角被称「灯」）；时间线倒错（ch1 初十 vs ch2 初七/初八）；红纸包道具链断裂（小满→萤→老妇→井台女，赠予者链不可还原）；角色卡漂移（小满性别、星象局机构名、住所三迁无过渡）
    结构机制（6） 金手指 ch2 退役（预知一用即弃、轮回机制零推进）；主角无欲望零主动；情绪配比全灰（平/悲九章、payoff 均半合米级）；对白全员同腔（格言腔问答体）；九章一模板（微差事-问答-记册-微钩收尾）；信息投放靠老人讲解
    文本指纹（3） 问答体（ch9 每 83 字一问号）；比喻同域（喻体全出自纸/账/册/布/绳，1.95 处/千字）；开头模板（9 章中 7 章以清点/数数开场）
    情感架构（3） 死者零回收（萤 ch2 后正文 0 次、塾师 2 章清零——被「不抒情不回忆」禁忌条款制度性切除）；回收周期 34 章（萤大回收规划在 ch36）；关系语法单一（女性角色全部以投喂建立关系、井台女零介绍登场）
    卷级节奏（4） 前 12 章节点表 6 章空白（ch5/6/8/9/10/11 无节点授权）；◆ 时点过晚（首个智力爽 ch24、情感锤 ch40、组织钩 ch48）；章长 7600-10000 与平台 3000 节拍错配（每万字节拍数 1 vs 头部 3）；槽位思维（留存锚/爽点拍查有无不评估重量）
    底层设计（1） 四代入引擎被大纲主动拆除（死亡免费/预知判废/欲望躺平/成长禁止——volume_map Objective 明写「让读者确认本书不是重生爽文」）
    管线盲区（3） 单章审计无跨章不变量校验（POV 审计对 ch1→ch2 断裂评 92 分通过）；anti-AI 词表 lint 管词面不管声口；audit_drift 有报警权无改向权（连续 5 章冷蓄压只发创可贴）；梗位蒸发（「班味的内核全球统一」规划 0 落地）、金句全静句、灰烬「墨」字钥匙读者不可解

    1. 大纲重构——引擎置换细则

    原则：不推翻设定，激活休眠资产。四引擎零件已存在于人物卡与故事框架（种子识衰减/怕忘记灯的脸/「攒东西的人」/贫嘴是铠甲），从修辞变机制。

    1.1 死亡筹码 → 轮回代价机制

    • 每渡一次丢一部分记忆，先丢最不重要的：无关之人的名字 → 技能细节 → 逼近「灯的脸」。死亡保命免费，但每次死亡是记忆赌博。
    • ch1 既有细节「想不起原身的名字」retroactively 成为机制首演扣费——正文已写好的伏笔零成本激活。
    • 渡鸦局卡片追踪启用为慢燃威胁；他人之死永久不可逆（良知之债主题原样保留）。

    1.2 信息优势 → 预知有限变现 + 账房降维

    • 规则成文：大节点准、细节错位（城破日/粮价走势/汛期可预知；个体位置/人心/执行路径不可知）。
    • 允许节点变现：ch4 盐价预测赚到第一笔钱（几十文级）而非换半合盐；变现引来注意（灰烬/官府盯上会算的人）= 收益自带风险成本。
    • 现代账房技能显性化为金手指（复式记账/统计/审计在土著眼里妖孽级），接「城里开始有人找他算账」的信用滚动。
    • 红线不动：预知救不了眼前人；变现限于自保与积累，救人靠组织。

    1.3 欲望 → 章级欲望阶梯

    卷一四级阶梯，每级具体 want + 可度量进度 + deadline（附籍册/征粮令天然是时钟）：

    活下来（1-12）→ 还清债立足（13-30）→ 护住名录上的人（31-48）→ 名录交出去立约（49-60）

    （章号按新粒度重排后等比例换算，见 #74。）

    1.4 成长 → 账本四轴结算

    「账单不许销账」从反成长宣言变成成长展示系统：

    轴 可见进度 卷一形态
    资产 钱袋余额（文） 300 文债 → 还清 → 第一桶金
    信用 谁找他算账 无名小子 → 「砖塔坊那个会算的」
    名录 《鉴录》名字数 0 → 逐个增加（每个名字=情感资产）
    组织 持灯人关系 老驼提前客串 → 行会规矩早种

    每卷卷末结算清单 = 遗物匣 + 四轴快照 + 渡鸦局档案卡彩蛋（既有）。

    1.5 文件改动面

    • story_frame.md：四引擎规则段落重写；前台故事补「每章主角想要什么」契约。
    • genre-config.json：新增市场参数——爽点拍密度（每 3 章 ≥1 智识小胜或变现落地）、情绪带（每章 ≥1 暖点或燃点，平/悲基调允许但有下限）、钩子分级（微钩/章钩/大钩；连续 2 微钩后必须章钩）、贫嘴声口密度下限、梗位配额（卷级）。
    • rhythm_principles.md：铺垫段占比 20-40% 收紧为 15-25%；单循环章节数按新粒度换算；四拍循环增「每拍重量下限」条款。
    • volume_map.md 卷一 KR 重排（→ #74，本章号目标均为新粒度口径，3200 字/章）：前 12 章节点空白 ≤2；智力爽 ◆ ≤5 章（≈1.6 万字）；变现 ◆ ≤8 章（≈2.6 万字）；灰烬以利害冲突形态出场（非传闻）≤12 章（≈3.8 万字）；萤回触每 5-8 章一次低成本触点，「萤染布」大回收节拍保留（章号按新粒度重排）；持灯人行会种子前移；灰烬「墨」字钥匙给读者显式解码工具（卷内两次不同化名同字 + 主角隐约察觉）。
    • 角色卡修复（→ #74）：小满性别按冯道原型定案（男，同僚对照面）；机构名统一（星象局→历法房）；deng.md 化名纪律（卷一=萤/那珂/帖兰，「灯」保留给末世）；主角登记名「临」全卷一致；住所轨迹写进卷纲；灯线每世化身独立建立场景。

    2. 章节粒度改革——方案 C 合同

    2.1 常量与数学

    • chapter_word.default 7600 → 3200（min 2800 / max 4000）；新增 primary_platform: qidian + 番茄档位（更目标 1800-2800）。
    • 总章数 1000 万 ÷ 3200 ≈ 3125 章；卷界按字数锚定不变（12 卷历史锚不动），卷内章数由 volume-budget 工具确定性重排（卷一 45.6 万字 → 约 143 章）。

    2.2 生成链路三改动

    1. chapter-planning：一次派发 = 2 章 bundle，输出两份独立备忘（各自章尾张力拍、场景字数预算、每场景收束钩声明），共享一次上下文读取。
    2. chapter-drafting：一次派发 = 1 场景簇 = 连续 2 章（约 6400 字），输出显式标记：===CH:47=== 章界 + <!--SCENE--> 场景界。
    3. 确定性拆分器（框架代码）：按 CH 标记拆 chapter-N.md；校验每章 2800-4000 字带、场景标记数 ≥2；标记剥离正文，场景边界 + 各场景末行写 sidecar（scenes.jsonl：字符位 + 收束钩原文）——发布层数据不靠猜。

    派发账：drafting/planning 均 3125÷2 ≈ 1563 次（×1.19，非 ×2.4）；G2/G4 逐章执行（本地代码）；LLM 审计同维度按簇批量（×1.19）。

    2.3 门禁与修订

    • G4 章尾张力拍逐章生效；新增：场景数校验、场景收束钩「声明 vs 实际」匹配。
    • 修订路径：批量产物先拆分再按章修订（修订粒度不变）。

    2.4 发布层 release_split v2（声明式，启发式退役）

    • 起点：1 章 = 1 更（重题直发）。
    • 番茄：以场景为原子打包（打包域=已收束窗口的场景序列，允许跨章组更）；硬规则四条——每更 1800-2800 字、更边界只落 SCENE 边界、每更必须以声明的场景收束钩收尾、禁切场景中部；违反即切分失败。
    • 旧九章全弃 → 无冻结/已发布包袱，旧启发式直接退役。

    2.5 风险与对策

    风险 对策
    章间弧线渗漏（2 章写成一条长弧） 双章备忘各自独立章尾拍 + 拆分器逐章字数带校验 + G4 逐章验钩；违例走章级重派
    批量上下文变大 6400 字低于已验证的 8000-10000 字单章负载，实际减负
    场景标记漏写 拆分器把标记缺失当硬失败（exit 1），熔断重派（沿用现协议）

    #72 · 平台章粒度改革（🟥 P0，依赖无）

    genre-config 常量与平台参数；planning 双章 bundle 契约；drafting 场景簇契约（CH/SCENE 标记 + 双备忘上下文）；确定性拆分器 + scenes sidecar；G4 逐章校验扩展（字数带/场景数/收束钩匹配）；release_split v2 声明式切分（旧启发式退役）；volume-budget 重排接线。验收：批量→拆分确定性、逐章 G4 全绿、番茄切分每更 100% 落声明钩、just check 全绿。

    #73 · 大纲引擎置换与市场参数（🟥 P0，依赖无）

    §1.1-1.4 四引擎规则进 story_frame；§1.5 市场参数进 genre-config；rhythm_principles 收紧（铺垫 15-25% + 重量下限条款）。验收：三文件重写落地、引擎规则有可测试表述（时间锚/金额/名字数可查）。

    #74 · 卷一卷纲重排与角色卡修复（🔴 P0，依赖 #72+#73）

    volume_map 卷一 KR 按 §1.5 重排（◆ 时点/节点密度/回触节点/灰烬钥匙/行会前移/欲望阶梯按新章号落位）；角色卡数据修复五项（小满性别/机构名/化名纪律/住所轨迹/灯线独立建立场景）。验收：前 12 章（新粒度）节点空白 ≤2、◆ 时点达标（口径同 §1.5）、卡-文一致预检过。

    #75 · 跨章不变量门（🔴 P0，依赖无）

    G 系新增六项跨章校验：①POV 人称一致（对前章）；②主角称谓字典（登记名/叙述代词白名单）；③时间锚单调不回拨（回拨须显式标记）；④物象道具链归属（owner 链可还原）；⑤角色卡属性一致（性别/机构/住所）；⑥资产连续性（账目钩跨章对账，收支跳变须有来源）。数据源：truth registry + 前章正文。验收：对旧九章跑门禁，五处硬伤全部被抓到（以旧章为回归测试集，门禁先证明能抓再上岗）。

    #76 · 声口与梗位执行层（🟠 P1，依赖 #73）

    贫嘴声口接线（protagonist voice_profile → drafting prompt 强制段 + 密度 lint）；梗位落地 lint（卷纲梗位表 → 章节正文出现检查，班味类卷内 ≥3 次）；对白差异化抽检（角色卡 voice_profile → 五角色口吻盲认测试）；金句静/燃双型配额（每卷燃句下限）。验收：新章声口密度达标、盲认通过。

    #77 · 文体指纹 WARN 闸（🟡 P2，依赖 #73）

    问号密度上限（问答体检测，分章对白域口径）；喻体域集中度检测（喻体词域分类 + 单域占比上限）；开头同构检测（N 章开头动作句式重复）；数数开头频次。全部 WARN 级进 audit_drift（不阻断，连续 WARN 触发 #78 改向）。验收：对旧九章复跑，指纹三项全部报警。

    #78 · 情感回触与爽点重量门（🟠 P1，依赖 #73+#74）

    死者回触频次门（主要死者 ≤8 章必有一次低成本触点：物象/小调/台词任一形态，物象追踪器已有可接线）；钩子分级轮换门（连续微钩上限 2）；爽点槽位重量评估（payoff 金额分级：智识小胜须产生可感知的资产/信用轴变动，半合米级不得计为兑现）；audit_drift 改向权（连续 3 章冷蓄压 → 强制下一章注入 escalation 节点而非补丁）。验收：注入路径有单测、回触门对旧九章报警。

    #79 · 重生成与验收协议（🟠 P1，依赖 #72-#78 全部）

    旧章删除流程（chapters/ 归档后清空，truth 滚动重置）；卷一重生成执行协议；验收判据：①#75 六项门零违例；②每章 2800-4000 字、G4 章尾钩全过、每章 ≥1 情绪高点；③前 12 章节点空白 ≤2、智力爽 ◆ ≤5 章、变现 ◆ ≤8 章、灰烬威胁 ≤12 章；④萤回触前 12 章 ≥2 次、贫嘴声口每章 ≥2 处、班味梗卷内 ≥3 次；⑤五角色对白盲认通过；⑥番茄切分每更 100% 落声明钩；⑦just check 全绿；⑧同一评分卡对新章复跑对标（诡秘/捞尸人开篇轴）确认差距闭合。

    4. 执行顺序
