    1. 定位与边界

    • 问题定义：现行文风控制面防御完备（防 AI 味五道硬闸 + anti-ai 禁令），但正向文笔资产为零——目标函数只定义「不难看」未定义「好看」。本 spec 交付正向资产层：句长落差、意象母题、金句工艺三项进指令层与测量环，可测代理进 WARN 闸。
    • 调研依据（存档于本 spec 头部决策路径与调研报告，例证见调研产物）：六位作者共性 = 长短句落差控节奏、画面靠具象名词、对话承载辨识度、煽情克制；反面教训 = 辞藻密度军备竞赛（「只学到辞藻，学不到自嘲」）与烽火式掉书袋在千万字尺度的疲劳风险。
    • 本 spec 改通用默认（style_seed.py 播种模板）与管线工艺；项目级 style_directives.md 覆写权归用户（write-if-absent 语义不变）。
    • 五道硬闸数值一律不动：转折词密度、AI 标记词、fatigueWords、字数契约、段落下限。唯一红线变更 = 破折号全禁转预算制（§5）。

## 节奏与句法

- 叙述句基带：12-25 字/句；对白保持短促（4-12 字/句）
- 长短落差（惊艳主引擎）：每场景 ≥1 句 ≥35 字奔涌长句（铺陈蓄势），
  其后 3 句内落 1 句 ≤10 字收割短句；连续 4 句两两互差 ≤5 字 = 节奏平段，须打破
- 段落形态：段均 2-4 句；成段叙述与单行对白交替，避免连续 5 段以上同构断行

## 意象与修辞

- 感官细节密度：每千字 3-5 处（触觉/听觉优先于视觉）
- 比喻带（双向，叙述文字口径）：每千字 2-4 处，低于下限 = 干燥、高于上限 = 堆砌；
  喻体必须取材当章场景物象，通用喻体（月光如水／如释重负／隔层毛玻璃类）= 违规
- 意象母题：每卷 1-2 个核心物象（卷纲「金句、母题物象与梗位」行指定），
  每章 ≥1 次变奏复现，语境须不同

## 金句

- 每章 1 处候选金句位（对白内或叙述收束处）；写法三选一：
  对比（两个具象并置见张力，如「账上得有数。账上得有过磅这一下。」）／
  反差（语境错位：宏大词入琐事，或琐细词入宏大）／
  口诀化（短句可记诵，如「白天漏灰，夜里漏光。」）
- 禁对仗堆砌、禁「不是…而是…」变体；金句落位后 2 句内收，不解释不展开

## 对白/叙述配比

- 对白占比目标：35-55%（引号内文字 / 正文总字）
- 关键对白三层：信息／关系变化／潜台词至少推进其一
  （潜台词三法：答非所问／一语双关／反话克制）
- 连续裸对白（无归属无动作）≤4 轮；对白带归属或动作拍的比例 ≥70%

## 章型微调（自动，通常无需改动）

- 上述各带是全书基带；drafting 按备忘段 1 的 chapter_role/chapter_type 在带内
  自动调制重心——高潮 = 斩截与咏叹交替（短句连排后允许 1-2 句 ≥35 字咏叹长句）、
  过渡 = 长句与意象、battle = 动觉意象、dialogue = 对带上沿，见 drafting 创作原则 7
- 仅当某章型需要越出基带时才在此按章型覆写

    对 v1 的变更点：基带 10-20→12-25；删除「≥16 字收束长句」伪长句定义，换奔涌/收割配额；感官密度 2-4→3-5；比喻单上限→双向带 + 喻体硬规则；新增金句节（含三写法与禁令）与母题行；对白新增三层要求；高潮调制改斩截与咏叹交替。金句示例取自星火 ch1 现成产出（自洽锚）。

    4.2 测量闭环升级（src/shenbi/skill_utils/style_learning/compute_stats.py + style-learning SKILL）

    • compute_sentence_stats 增 ≥35 字句占比（奔涌率）；新增 count_similes。单信源落点 = gates/shared.py：segment_sentences（连同其私用常量 QUOTE_PAIR）自 compute_stats 迁入 + count_similes（闭集 + find_quote_spans 非对白剥离）新增；compute_stats 与 G4.cd 同向导入（既有依赖方向 skill_utils→gates 不变；compute_stats re-export segment_sentences 保 API 兼容——gates 层零 skill_utils 导入的仓规不被打破）。
    • 比喻闭集（子串计数，非对白文本）：像、仿佛、宛如、宛若、恰似、如同、似的——密度 = 计数 / 非对白文本字数 × 1000。非对白文本 = strip_narrative_body(content) 先剥五类命名节（含 PRE/POST 裸 H2 形态——真实产物存在裸 H2 形态，tests/fixtures/chapter-*-draft.md 实证，POST 金句/奔涌摘录行恰是含喻词概率最高的文本，不剥 = 分子污染；与 surge 同域同先例；compute_all_stats 的 F634 现状只剥 META 包裹，本批顺带修复该既有统计污染）+ META 包裹，再剥离引号内文字后的正文（引号对覆盖 「」『』""“”，复用 cjk.find_quote_spans）；分母与分子同域（非对白文本的非空白字符数，含 H1 行）——若沿用 total_chars_md_text（含对白）作分母，对白占比 35-55% 下测值系统性下移约半，[2,4] 带界与 §2 模板「每千字 2-4 处」的写作者语义错位，故分母取非对白域。「像」子串匹配含「好像/就像」复合形式与名词内嵌（影像/画像/像样等）——两类误计均为接受的 WARN 级精度损失；仿佛/如同 计入 FATIGUE_BASE 疲劳预算（≤8/章）且 仿佛 另受 AI 标记词 ≤1 次/章硬闸——闭集七词中两词受限，实际可用喻词以 像/宛如/宛若/恰似/似的 为主，带内达标现实可行（试点观察项 6 人工抽检覆盖）。

    4.4 G4.cd 三 WARN 谓词（确定性；WARN 不阻拦，进审计报告供裁决）

    id 口径（全部操作化） 触发
    G4.cd.surge 计数域 = strip_narrative_body(content)（剥 PRE/POST META 块后的叙述正文，与 G4.transition 同域——防 POST 自检清单喂饱闸，probe escalation #4 同型）；句切分与 compute_sentence_stats 同源（segment_sentences）；句长 = 非空白字符数（含标点）；叙述句 = 引号内字符占比 <50% 的句；计数章内句长 ≥35 的叙述句 计数 < max(1, total_chars_md_text 章字数 // 3000)（配额分母钉死 gate 字数地板口径——escalation #4 先例；切分与 §4.2 同源；指令层按场景、闸按章做下限代理——每场景 ≥1 在章级聚合为 ≥字数//3000；配额分母取全章口径，对白占比高的 dialogue 章配额相对叙述域偏宽——温和方向，接受；7145 字章即 <2 处；1700 字探针章即 <1 处）
    G4.cd.simile_band §4.2 闭集子串计数于非对白文本（strip_narrative_body 域 + 剥引号），密度 = 计数 / 非对白文本字数 × 1000 密度 ∉ [2, 4]/千字（低 = 干燥，高 = 堆砌）
    G4.cd.golden_slot PRE_META 块含行首 - 本章金句位 且半/全角冒号（[:：]）后至行尾值非空——「空」= strip 空白、去首尾 [] 后为空字符串或恰为 无/N/A/待定（全角冒号容错对齐 G4.cp payoff 拍/emotion_tone 谓词先例）；POST_META 块含金句摘录项（行含「金句位」且冒号后至行尾非空——不耦合方括号字面，摘录带引号写法同样命中） 任一缺失
    • 俗套喻体与金句质量判定不进 G4（确定性闸管不了审美）——simile_band WARN 的 reason 文本附「俗套喻体抽检」提示，归审计裁决复核；试点期人工抽检（§6）。
    • 母题行（PRE）不设独立 WARN：变奏复现的判定开放性强，机器只能查行存在、价值低，且避免 WARN 泛滥；母题质量归审计面抽检。

    5. P3 — 框架红线（两项）

    5.1 破折号预算制（anti-ai-reference.md 全禁 → 预算；本 spec 即框架变更流程载体）

    • 每章 ≤2 处，仅限两种用法：咏叹收束（长句末尾情绪延宕）、对话打断（话被截断）。解释补充用法（「他深吸一口气——这不可能」类）仍然全禁。
    • 执行面（活执法面 = review-group-craft 检查 3——review-anti-ai 已 RETIRED 2026-07-19，chapter_loop.py:297 迁移表映射 None，只改退役文件 = dead-wire）：anti-ai-reference.md 句式禁令表该行改写（drafting 侧自检参考，仍活）；shenbi-review-group-craft SKILL 检查 3「破折号检测」补预算口径——每章 >2 处 = ERROR；≤2 处但属解释补充用法 = ERROR；合法用法 ≤2 = pass（LLM 执行项，计数 ——/──）；review-anti-ai SKILL 检查 3 顺手同改但注明 reference-only 不算执法面。计数口径用 cjk.py 破折号类（——/──），style-learning 统计指标目录「### 6. 标点密度」（每千字破折号数）本就测量，作观察项。
    • 依据：维基百科《AI 生成文的特征》自标破折号在中文语境为弱信号；咏叹破折号是烽火/猫腻文体核心标点。docs/framework/style-directives.md §4 中「解除破折号禁令须走框架变更」条款同步改写为预算制表述。

    5.2 drafting 温度 0.85 → 0.90（executor_config.toml，单臂变更）

    • 理由：对抗 RLHF 均值回归（「意料之外的妥帖比喻」被淘汰的直接补偿旋钮）；双跑 A/B 成本一整卷不成立，卷一 v2 首跑即单臂观察，对比 vol1 首跑段历史基线（~$0.18/章、escalation 率）。
    • 回退条件：主判据 = 章均成本 >1.5× vol1 首跑段实录（ch1-4 段成本台账 cost/token-ledger.jsonl 归集，约 $0.18/章）；辅判据 = 仍活故障族 decisions-stub 复现 >1.5×（首跑段 2/5 章）；空正文族不计入（thinking=low 已修复，probe 文档明示本跑预期 0——修复前 9 次/4 章仅作历史上限锚注记）→ 任一触发回 0.85 并记档（观察项，不动代码结构）。
