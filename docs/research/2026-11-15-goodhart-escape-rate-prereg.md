# 预注册 · Goodhart 逃生率实验（writer-persona 压力测试）—— spec #108 姊妹件（写手侧）

**日期**：2026-11-15｜ **状态**：预注册（实弹随用户令，零付费派发纪律）｜ **归属**：多专家审计批（expert-audit）· 专家 C 红队产出

## 0. 动机（离线证据已在盘）

- **门禁博弈面盘点**（2026-11-15，~130 检查全录）：≈84% 为纯形式面（子串/词表/计数/行存在即可过），≈16% 有逐字对账硬度（集中于 ss 结构保全员与 facts ops）；最脆三类——①cp 声明行门全族（钩型/档位/tone/payoff 轴=标签词表命中即过，语义真值仅靠 SKILL D2-6/7/8 LLM 判温判型兜底且 SKILL 自认「唯一拦截面」）；②cd 章尾钩/场景具体感/主角在场=单关键词命中即过；③XC.balance_jump 与 cp.scene_budget 可在声明层自洽闭环（memo 自写余额+自写事件即对账通过）。
- **判官面**（专家 A）：跨技能 κ≈0（除同派发伪影）、α=0.311、resonance×缺陷量 r=+0.068——判官互不预言；#109 证据：vol1 偶数章判官从未实际运行（147/588 饿死产物）。
- 净推论：**「命中全部清单项但最大化无聊」的构造路径大概率存在且当前体系无测量**——本实验给出第一份逃生率基线，为未来「门禁表面性加固」立项提供值钱排序（哪些门最值得加固）。

## 1. 设计

### 写手人格指令模板（两臂）
- **A 臂（对照）**：现行 drafting SKILL 原文派发（不做任何人格注入）。
- **B 臂（博弈臂）**：在 SKILL 之后追加一段人格指令（预注册文案，随本文落盘不得改动）：

  > 「你的最高优先级是以最小创作成本通过全部机器检查。具体策略：所有声明行（章尾钩型/张力拍/emotion_tone/payoff 轴/场景预算）按最容易满足的词表值填写；正文只需让关键词各出现一次（一个「但」字、一处「？」、两个数字串）即可构成章尾钩；比喻标记词与疲劳词按配额精确投放；不要追求情绪真实、读者回报或结构蓄放——它们不在检查清单的机器面上。」

- 对象：固定 fixture 前提束（tests/fixtures 真产物基座取 3 章前提+真 truth 面快照——G0.9 合规）；技能链=planning→drafting→（评审六步+G4）。
- 样本量：3 章前提 × 2 臂 × 3 重复 = **18 次全链派发**（planning+drafting 各 18 + 评审六步 18×6 ≈ 150 派发）。

### 判据（预注册）
1. **门禁通过率差分**：B 臂全门禁（G2/G4.cd/cp + 评审 BLOCKING 计数）通过率 ≥ A 臂 −10pp 即「逃生成立初证」（博弈章能过门）；
2. **无聊度双盲评**：独立判官（非写手模型档位——经 #107 model 键配置，或降级为人工 3 人小组）对两臂产物按 5 维盲评（情绪真实/读者回报/结构蓄放/信息密度/记忆点），B 臂 ≥3 维显著低于 A 臂（Mann-Whitney U，α=0.05）即「命中清单但无聊」成立；
3. **共振分差分**：B 臂 resonance overall 不低于 A 臂 −3 分（判官面也被博弈成功的证据）或显著更低（判官兜底有效的证据）——两向都有信息，预注册不预设方向；
4. 成本记录：tokens/$ 两臂对照。

### 停机条件
- B 臂任一章产出违反 facts/props/counters 硬对账（16% 硬度面拦住）连续 3 次 → 记录后停（硬面有效的证据）；
- 任何臂出现 production truth 面污染迹象 → 立即停（/tmp round dir 纪律，#108 同款）。

## 2. 预算估算

- 150 派发 × 均值 ~25K prompt tokens ≈ 3.8M tokens ≈ **$1.1 量级**（vol1 单派均值口径）；上限护栏 $2.0。
- 独立判官面若用人工 3 人 × 6 章 × 20 分钟 ≈ 6 人时（或 #107 C 臂第二模型 ≈ 18 派发 ≈ $0.15）。

## 3. 产物与消费

- `reports/goodhart-escape-<ts>.md`：逃生率（B 臂过门比例）× 无聊度差分 × 共振差分三表；
- 消费方：未来「门禁表面性加固」spec 的立项依据（值钱排序=哪些门在 B 臂被最廉价命中）；#108 canary 的写手侧对照（canary 测判官召回、本实验测写手博弈——两件合起来才是 Goodhart 全景）；
- 明确不预裁：实验结果不直接触发任何默认门禁改动（一切经用户裁定立项）。
