# 元审层第三方席位协议（meta-review · v1 · 2026-11-22）

> **定位**：跨 spec／跨工件的**横切面**评审协议。横切面是 per-spec 环路结构上做不到的视角——单份 spec 的审查者看不见跨 spec 依赖边与系统性模式（「一批门全部恒真」「评分→选材→生成→同一评分者」类缺陷只在此层暴露）。**不入 `/sdd-next` 执行环路**（2026-11-15 用户裁定：异血统多样性归立项／元审层）；协调者=GLM（裁决／亲验／infra），外部席位=本机已配置的异血统模型。
>
> **首轮流标定底账（2026-11-22 四臂盲测）**：GLM×五问基线／GLM×五问+lens／DS-flash×lens／MiniMax×lens，四段脱敏材料（2 阳性=历史真缺陷；2 拟阴性实均有真问题——阴性误标是本轮方法论教训）。读数：基线五问强（6 类历史缺陷中 5 类）但漏三类——**上限触顶后永久熄火**、**层级错位（整体分选局部材料）**、**判据可达性算术**；DS-flash 与 MiniMax 各有 ≥4 项 GLM 双臂全漏的独有真发现；MiniMax 1 项代码级主张被亲验驳回（落在其自declared 不可靠面内）——亲验纪律实证必要。同日另两个独立会话对同材料盲审，结果收敛。

## 1. 触发面（按杠杆排序；命中任一 → 协调者向用户建议启动一轮元审）

1. **共享仪器变更**：评分判官 prompt／rubric／外部锚点集／模型档位任一变更——所有以该仪器为基准的门／阈值／锚点／预注册同时失效，系统内无自愈机制（两席位独立点名「只加一个就加这个」）
2. **shadow→armed／消费态升级**：「只算」→「真路由」、「研究结论」→「生产接线」——唯一能把预测点火率与实际点火率对账的时刻
3. **判据冻结前**：预注册判据表／spec 验收条款**定稿之前**（非文档写完前）——验收一旦写死，其后所有实施都在该判据下做
4. **跨 spec 依赖边建立**：新机制把另一 spec 的**未决结论**当前提使用（实例：风格学习第四源把外部效度研究的未出结论当已成立信号）
5. **分布哨兵越界**：分数带漂移／点火率异常——按分布事件触发，非按文件计数（「同域合入 N 份」看不见跨域耦合）
6. **批级兜底**：新批 sibling spec 立项前

## 2. 席位与运行纪律

- **席位**：DeepSeek（`deepseek-v4-flash`）＋ MiniMax（`MiniMax-M3.1-Flash`），双席**独立跑**（同 payload、互不通气）；一致项高信，分歧项列仲裁清单交用户
- **协调者（GLM）职责**：构造脱敏 payload／逐条亲验产出／裁决与立项建议。**裁决权不外放**——席位只产可逐条证伪的清单
- **产出契约**（席位 prompt 必含）：每条缺陷附①定位=被审文本原文短语（逐字）②问题一句话③严重度 Critical/Important/Minor④修法方向一句话⑤「若我错了会看到什么」（可观测反例）；证据分级 **[矛盾]**（文本内部可复算）vs **[缺位]**（文本未写，须回原文核）——[缺位] 类只在全文复核后采纳；**「未见缺陷」是合法产出**，禁止配额式硬找
- **亲验义务**：外部席位产出 **100% 回协调者逐条亲验**——代码级主张（行号／常量／测试形态）必开文件核对（实证：2026-11-22 MiniMax「测试硬编码 CAP」主张被亲验驳回，实际为 import 派生）；可复算主张（算术／CI 宽度／边界例）必独立重算
- **降权三信号**（任一出现即整批降权或重跑）：①**引文漂移或复算不回**（定位短语在原文撑不起所指缺陷）；②**配额式产出**（从不判「未见缺陷」／条数雷同／用文风级小毛病填满干净段）；③**与 prompt 提示语近义重复**（头号结论几乎是审查问措辞的复述=顺从而非发现，只计「确认」不计「新增」）
- **payload 纪律**：自包含脱敏（摘录编号卷标、去 spec 编号与仓库路径）；外部席位**禁读仓库**（防见到含答案的修订版材料）；被审文本入 prompt 时按 `review-rubric.md` 头部「外部内容定界」加围栏前导；**材料必含 ≥1 段真阴性对照**（防产出压力假阳——首轮阴性误标教训）
- **禁区**（席位不做的）：仓库事实核对／历史裁定冲突判断／「是否值得做」的价值裁决／实施与 infra——这些归协调者与用户

## 3. 与执行环路的关系

- 环路内审查（阶段 1 五问＋测量语义 L1-L5、阶段 3/5 rubric 注入）保持单血统（2026-11-15 裁定⑥）；本协议的发现按既有入口回流：spec 级 → 价值门 REWRITE／新 spec 立项（INDEX 预答栏）；门／阈值级 → 对应标定机制（shadow 期／gate-power 回放）
- 每轮元审结果**追加式**记入本文件「标定底账」——席位判别力随轮次积累，类比 gate-power baseline 指针的维护方式
