# Spec #72 · 平台章粒度改革（chapter-granularity）

> **Date:** 2026-10-25 | **Status:** Active | **Severity:** 🟥 P0（地基） | **方法:** 方案 C——平台章原生粒度 + 场景簇批量派发（一次派发 2 章）+ 声明式发布切分 | **系列:** 市场适配层（novel-market-overhaul） | **依赖:** 无 | **范围:** genre-config 常量与平台参数 / shenbi-chapter-planning 与 shenbi-chapter-drafting 契约 / 确定性拆分器 + scenes sidecar / G4 逐章校验扩展 / release_split v2 / volume-budget 重排接线

> 源自 2026-10-25 总设计 `2026-10-25-novel-market-overhaul-design.md` §2（诊断背景与决策路径见总设计 §0）。用户决策：双平台（起点粒度生成为主、番茄发布层适配）；方案 C（原生+批量派发）。

## 1. 定位与边界

- 问题：`chapter_word.default=7600` 锚定了 1316 章的生成粒度，每万字节拍数 ≈1（头部 ≈3）；release_split 启发式切分不带爽点/钩子意识，切分点打乱节拍布局。
- 本 spec 改生成与发布的**粒度合同**，不改内容规则（引擎/节奏归 #73/#74）。
- 卷界按字数锚定不变（12 卷历史锚不动）；旧九章全弃，无迁移包袱，旧启发式直接退役。

## 2. 施工面

1. **常量与参数**（`genre-config.json` + `src/shenbi/config`）：`chapter_word.default` 7600→3200（min 2800 / max 4000）；新增 `primary_platform: qidian` 与番茄档位（更目标 1800-2800）。总章数 ceil(1000万÷3200)≈3125。
2. **chapter-planning 双章 bundle**（`skills/shenbi-chapter-planning/SKILL.md`）：一次派发输出两份独立备忘——各自章尾张力拍、场景字数预算（2-3 场景/章）、每场景收束钩声明；共享一次上下文读取。
3. **chapter-drafting 场景簇契约**（`skills/shenbi-chapter-drafting/SKILL.md`）：一次派发 = 连续 2 章（约 6400 字）；输出 `===CH:n===` 章界 + `<!--SCENE-->` 场景界标记；每章末尾必须落在备忘声明的章尾钩上。
4. **确定性拆分器**（`src/shenbi/pipeline/` 新增）：按 CH 标记拆 chapter-n.md；校验每章字数带 2800-4000、场景标记数 ≥2、标记缺失=硬失败（exit 1，熔断重派）；标记剥离正文，场景边界 + 各场景末行写 sidecar `scenes.jsonl`（章号/字符位/收束钩原文）。
5. **G4 逐章校验扩展**（`src/shenbi/gates/g4/`）：章尾张力拍逐章生效；新增场景数、收束钩「声明 vs 实际」匹配校验。
6. **release_split v2**（`tools/release_split.py`）：起点档 1 章=1 更（重题直发）；番茄档以场景为原子打包（打包域=已收束窗口场景序列，允许跨章组更），硬规则四条——每更 1800-2800 字、更边界只落 SCENE 边界、每更必须以声明的场景收束钩收尾、禁切场景中部，违反即切分失败。旧启发式分类器退役。
7. **volume-budget 重排接线**（`tools/volume_budget.py` 既有确定性写回）：卷内章数按 3200 重排（卷一 45.6 万字 → 约 143 章）。
8. **审计批量**：LLM 审计同维度按簇批量派发（×1.19 而非 ×2.4）；G2/G4 逐章执行（本地代码无 LLM 成本）。

## 3. 风险与对策

| 风险 | 对策 |
|---|---|
| 章间弧线渗漏（2 章写成一条长弧，第二无独立钩） | 双备忘各自独立章尾拍 + 拆分器逐章字数带校验 + G4 逐章验钩；违例章级重派 |
| 批量上下文变大 | 6400 字低于已验证的 8000-10000 字单章负载，实际减负 |
| 场景标记漏写 | 拆分器硬失败熔断（沿用现协议） |

## 4. 验收

- 拆分器对批量产物确定性拆分，逐章字数带/场景数/钩匹配校验全绿
- G4 逐章（非逐簇）通过；标记缺失路径熔断可用（负例测试）
- 番茄切分：每更 100% 落在声明的场景收束钩上、零场景中部切割（含跨章组更用例）
- `just check` 全绿；章数预算重排幂等复跑一致
