# Spec #76 · 声口与梗位执行层（voice-meme-wiring）

> **Date:** 2026-10-25 | **Status:** Active | **Severity:** 🟠 P1 | **方法:** 人设卡声口 → drafting 强制段 + lint；梗位表 → 落地检查；对白差异化盲认 | **系列:** 市场适配层（novel-market-overhaul） | **依赖:** #73（市场参数先行） | **范围:** skills/shenbi-chapter-drafting 声口接线 / 梗位 lint / 对白差异化抽检 / 金句双型

> 源自总设计 §3。问题依据：protagonist.md 定「贫嘴吐槽役、越惨越贫」，九章正文贫嘴声口出现 ≤4 次；volume_map 梗位「班味的内核全球统一」规划 0 落地；十余角色对白全员同腔（格言腔问答体），遮署名无法盲认；金句全是收敛型静句。

## 1. 施工面

1. **贫嘴声口接线**：protagonist voice_profile（账房腔/危险时先口算成本越惨越贫/自嘲式反问收尾）注入 drafting prompt 强制段；每章贫嘴吐槽密度下限（genre-config #73 参数）+ lint（口癖句式/账房比喻动 词族计数）。
2. **梗位落地 lint**：卷纲「金句、母题物象与梗位」行的梗位清单 → 卷内正文出现次数检查（班味类 ≥3 次/卷）；缺额 WARN 进 audit_drift，卷末仍未达 = FAIL。
3. **对白差异化抽检**：角色卡 voice_profile（口癖/句长分布/语气词）→ 对白归属抽检；五角色口吻盲认测试（遮署名混排对白，辨识率达标）；drafting prompt 按在场角色注入各自声口要求。
4. **金句双型配额**：金句位设计扩双型——静句（冷/准/收敛，既有工艺）+ 燃句（可传播的狠/燃，网文引用型）；每卷燃句下限，drafting 金句位备忘声明类型。

## 2. 验收

- 新章贫嘴声口密度达标（每章 ≥2 处，lint 计数）
- 梗位 lint 对卷纲梗位表全覆盖，班味类卷内 ≥3 次落地
- 五角色对白盲认通过（盲测辨识率 ≥4/5）
- 金句双型配额进备忘声明与 lint
