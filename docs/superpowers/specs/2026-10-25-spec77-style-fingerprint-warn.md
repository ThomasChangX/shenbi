## 1. 四项指纹指标

1. **问号密度**：对白域口径每千字问号数上限；连续两章超限 = WARN「问答体退行」
2. **喻体域集中度**：喻体词域分类（纸账册/粮食物/器物/自然/身体/其他），单域占比 >70% 且总量超带 = WARN「比喻同域」
3. **开头同构**：近 N 章开头首个动作句式聚类（清点/数数/拆包/量取动词族），同族连续 ≥3 章 = WARN「开头模板」
4. **数数开头频次**：卷内以计数动作开篇的章节占比上限
