# Spec #78 · 情感回触与爽点重量门（recall-payoff-weight）

> **Date:** 2026-10-25 | **Status:** Active | **Severity:** 🟠 P1 | **方法:** 频次门 + 重量分级 + audit_drift 改向权 | **系列:** 市场适配层（novel-market-overhaul） | **依赖:** #73、#74 | **范围:** 回触频次门 / 钩子分级轮换门 / 爽点重量评估 / audit_drift 改向权

> 源自总设计 §3。问题依据：萤 ch2 死后正文 7 章零提及、塾师 2 章清零——被「不抒情不回忆」禁忌条款制度性切除；九章章尾全是同频微钩（未答之问/未说破之瞒变体）；payoff 槽位全达标但载荷均半合米级（槽位思维查有无不评估重量）；audit_drift 连续 5 章记录「冷蓄压」但修复动作被限定为补丁（加一处温度），无改向权。

## 1. 施工面

1. **死者回触频次门**：主要死者（有角色卡或有情感投资的死者 registry）≤8 章必有一次低成本回触——物象/小调/台词任一形态即计；接物象追踪器（#75 owner 链）与角色 registry；超窗 = WARN + 备忘强制注入回触拍。禁忌条款同步修订：「不抒情不回忆 X」改为「不直给抒情；回触须以物象/小调/台词低成本形态」。
2. **钩子分级轮换门**：微钩/章钩/大钩三级（#73 genre-config 定义）；连续微钩上限 2，超限 = FAIL（章尾张力拍校验扩展分级）。
3. **爽点重量评估**：payoff 拍分级——智识小胜须产生**可感知的四轴变动**（资产增额/信用事件/名录+1/组织节点任一登记），纯口头/半合米级不得计为兑现；备忘 payoff 行须声明轴与量。
4. **audit_drift 改向权**：连续 3 章冷蓄压（情绪带低于 #73 下限的 WARN 累计）→ 下一章备忘强制注入 escalation 节点（卷纲节点表取用），而非仅「补一处温度」；连续 5 章 → 熔断停等人工。#77 的连续 WARN 计数器接入同一改向通道。

## 2. 验收

- 回触门对旧九章报警（萤超窗 7 章）；修订后禁忌条款不再零回触
- 钩子分级对旧九章章尾序列判「连续微钩超限」
- 重量评估有单测（半合米级不计兑现、四轴变动登记才计）
- 改向路径有单测：3 章冷蓄压 → 备忘注入 escalation；5 章 → 熔断
