## 六、总结

- git 历史整体健康：无 revert 震荡、无凭证残留、无二进制滥用；主要风险是**"完成度承诺悬空"**——revert 承诺的 follow-up（T1501）、de-dup 清单漏项（T1503）、spec 托付蒸发（T1505）、迁移 shim 无收尾（T1506）、设计工作滞留未合分支（T1502）同属一个家族：**交接只写在 commit message/注释里，缺追踪载体**。
- 体量面唯一实质风险是 novel-output 22.7MB 反忽略（T1504），趁 history rewrite 尚未不可行前收窄规则成本最低。
- churn 治理建议：以"src/*.py 且非生成物"为口径监控，聚焦高 churn 高密度（chapter_loop/dispatch_helper）与低 churn 高密度（cli/scoring/phase_runner）两个象限，而非全局 churn 排行。
