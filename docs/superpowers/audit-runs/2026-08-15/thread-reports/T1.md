### T101 | file_type="decisions" 使 chapter-drafting/short-drafting 的 .md 主产物静默绕过 G2 全部章节质量检查 | gate-bypass | P0

**证据**（实跑 /tmp/t1x/test_dft.py + test_g2.py）:

1. `derive_file_type` 实测（executor.py:69-90，truth 优先级 > decisions > chapter）:
   ```
   shenbi-chapter-drafting  writes=[chapters/chapter-N-decisions.json, chapters/chapter-N.md]  file_type=decisions
   shenbi-short-drafting    writes=[chapters/chapter-N.md, short/short-N-decisions.json]      file_type=decisions
   shenbi-chapter-revision  writes=[chapters/chapter-N-revision-decisions.json, ...]          file_type=decisions
   ```
   `chapters/chapter-N.md` 在 truth-files.yaml:51 是 `kind: chapter`（非 truth），不命中 `_truth_file_set()`；`chapters/chapter-N-decisions.json`（yaml:54）命中 `_decisions_file_set()` → 返回 "decisions"。

2. g2.py:76-84：`if file_type == "decisions": if not fp.endswith(".json"): continue`——.md 文件在循环中被无条件 continue，**无任何检查项、无 SKIP 记录**。

3. 构造实测（chapter-99.md 约 10 字、无 PRE_WRITE_CHECK/POST_WRITE_SELF_CHECK + 合规 decisions.json）:
   ```
   S1  mixed(.md违规 + .json合规), file_type=decisions : PASS   (.md 仅 G2.1-2.3 存在性 PASS)
   S1b 同一 .md, file_type=chapter                     : FAIL   (G2.6 字数下限 + G2.8 + G2.9)
   S2  .md only, file_type=decisions                   : PASS
   ```

4. 受影响调用路径：dispatcher `executor.dispatch()`（executor.py:176,213）与 phase_runner `cmd_post_skill`（phase_runner.py:202-213，M8 注释自证作者只防了"rglob 只找到 .md"的 crash 场景，混合输出时主产物静默跳过）。phase_runner fallback（phase_runner.py:208-210）仅在 `output_files` 为空时触发，文件存在时不救。

**根因**: file_type 是按技能整体推导的单一标量，而技能输出是混合类型（.md 主产物 + .json sidecar）；G2.dec 分支用 `continue` 处理 .md 而非按扩展名分流检查。

**验证**: 上述 S1/S1b/S2 三场景构造复现，PASS/FAIL 对比确凿。

**影响面**: dispatcher T1 测试路径与 phase_runner T2 路径上，chapter-drafting（全链核心技能）、short-drafting、chapter-revision 的全部 .md 主产物（章节正文、快照）在 G2 下零检查即 PASS——字数门、PRE_WRITE/POST_WRITE 自检块、占位符、截断检测全部失效。pipeline 路径不受影响（executor.py:211 显式 skip G2 转由 G4/G6）。

**建议方向**: G2 内部按扩展名分流（.md 走 chapter 检查、.json 走 G2.dec），或 derive_file_type 返回类型列表/逐文件推导；.md 跳过时至少落 SKIP 记录。

### T104 | G2 与 G4 对同一 decisions 文件判定分歧 15/145：G2 的 raw_decode 截断恢复放行"JSON+尾巴"损坏文件，拼接检测存在无-$schema 盲区 | gate-divergence | P2
