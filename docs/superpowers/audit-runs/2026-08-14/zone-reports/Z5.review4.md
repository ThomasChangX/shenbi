### F531 | 无 state 的 dispatch 调用路径（genesis/closure/triggers/audit_layer/parallel/CLI）TokenLedger 零落账：`_record_token_usage` 以 `if state:` 为闸门，project_dir 可用也不写 → 大部分 pipeline API 成本系统性缺失 | 计量缺口 | **P2**（见严重度异议 S1） | dispatch_helper.py:1297-1299,1332-1341；genesis.py:302；closure.py:253；cli.py:123,751；revision_router.py:160；triggers.py:561；parallel_dispatch.py:86；audit_layer.py:170

**证据**：
- `_log_token_usage`（dispatch_helper.py:1297）：`if state: _record_token_usage(...)` — ledger 写入被 state 存在性闸门挡住；`_record_token_usage` 的 docstring（:1307-1312）明示"Now also appends a record when project_dir is available"——与实际代码（state 闸门）矛盾。
