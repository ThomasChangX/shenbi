### F498 | G5.3 数值一致性检测完全死路：num_pat 单捕获组 + `m.group(2)` IndexError 被 `except Exception: continue` 吞掉 → numeric 冲突永不报告；测试显式钉死惰性行为（"source bug"） | error | P2

- 证据: src/shenbi/gates/g5.py:153（`num_pat = re.compile(r"(\d+)\s*(?:个|种|人|章|次|处|条|名|位|倍|%|万|千|百)")`——**仅 1 个捕获组** `(\d+)`，单位组 `(?:...)` 非捕获）、:159（`unit = m.group(2)`——正则只有 group(1)，**首个数值匹配即抛 IndexError**）、:171-172（`except Exception: continue`——IndexError 被吞，该文件被跳过，`numeric_registry` 永不填充）。tests/unit/gates/test_g5.py:139-163（`test_g5_numeric_inconsistency_not_detected_pins_inert_behavior` docstring 自认："The source num_pat regex is `(\d+)\s*(?:个|种|人|...)` — only ONE capture group. The loop body reads `m.group(2)` (the unit), which raises IndexError, caught by the per-file `except Exception: pass`."；断言 `assert not any(mf.startswith("G5.3:numeric")...)` 钉死惰性行为，注释 "If the group-2 bug is later fixed, this test will flip"）。
