## 1. findings（F600–F699）

### F601 | detect_drift 对话密度塌陷触发被 `>5.0` 严格比较吞掉（max(…,5.0)=5.0 不满足 >5.0） | error | P1
- 证据：`src/shenbi/skill_utils/drift_detection/linguistic_drift.py:215`（`max_deviation_ratio = max(max_deviation_ratio, 5.0)`）、`:218`（`is_drift = max_deviation_ratio > 5.0`）、docstring `:185-188`（明确声明"dialogue density collapses to <20% of baseline"为触发条件）
- 根因：对话塌陷分支把比值设为恰好 5.0，但 is_drift 用严格 `> 5.0` → 纯对话塌陷场景 is_drift=False；且 severity 分支 `:226` 依赖 `is_drift` → severity=NONE。文档承诺的触发条件在唯一触发场景被 off-by-one 吞掉。
- 验证命令+输出：
  ```
  PYTHONPATH=src python3 -c "..."（dialogue_density 10→1，其余指标不变）
  dialogue-collapse-only -> is_drift: False | severity: NONE
  对照组 em_dash 6x（ratio=6.0）-> is_drift: True | severity: WARN
  ```
- 影响：该确定性助手替代 LLM 判断、喂给 drift-guidance gate 与 chapter_loop 的 3 层干预；对话塌陷（角色消失信号）被静默放过 → pipeline 继续推进。
- 建议方向：对话塌陷分支改为 `max(..., 5.01)` 或单独 OR 条件（`dialogue_ratio < 0.2 or max_deviation_ratio > 5.0`）；补单测（baseline dialogue>0、当前 <20% 时 is_drift=True）。

### F604 | compute_stats.compute_punctuation 引号桶 ASCII 引号重复计数（每 `"` 计 2 次） | error | P2
- 证据：`src/shenbi/skill_utils/style_learning/compute_stats.py:27`（`"引号": "\"\"''「」『』"` 含重复字符）、`:226`（`sum(text.count(c) for c in chars)`）
- 根因：chars 串中 `"` 与 `'` 各出现两次 → 每次 `text.count` 求和重复；ASCII 引号对计 4、全角「」对计 2，密度口径不一致。
- 验证命令+输出：`compute_punctuation('他说"你好"。')` → `{'count': 4, 'per_1000': 571.4}`（一对 ASCII 引号应为 2）。
- 建议方向：`for c in set(chars)` 去重或修正字面量；补单测。

### F605 | compute_linguistic_metrics 空 system_terms 时正则匹配空串 → 密度 ~1000‰ 假 ESCALATE | error | P2
- 证据：`src/shenbi/skill_utils/drift_detection/linguistic_drift.py:107`（`re.compile("|".join(re.escape(t) for t in cfg.system_terms))`）；配置驱动 `:80-84`
- 根因：genre-config.json 配 `system_terms: []`（或字段缺失被置空）时 `"|".join([])` == `""`，`re.findall("", text)` 每个位置匹配 → 密度 ≈ (n+1)/n*1000 ≈ 1000‰，远超 ESCALATE 阈值 100 → 健康章节假阳性暂停 pipeline；字符串误配（如 `"参数"`）还会按字符拆词。
- 验证命令+输出：`DriftConfig(system_terms=[])` → `system_term_density: 1125.0`。
- 建议方向：空列表返回 0；校验类型（非 list → 回退默认）；补单测。

### F606 | update_genre_config 的 floor 下限规则只认 int：float/str 绕过 | error | P2
- 证据：`src/shenbi/config/config_coherence.py:121-130`（`isinstance(new_value, int)` 才拦 `new_value < resonance_revision_trigger`）

- 建议方向：数值比较用 `isinstance(new_value, (int, float)) and not isinstance(new_value, bool)`，非数值抛 ConfigError；补单测。

## 3. 通用维度小结

1. **正确性**：trace/records/text 核心正确；主要问题集中在确定性助手边界（F601/F605）与统计口径（F604/F608）。
2. **错误处理**：replay 静默截断（F609）、read_chapters 静默吞错、parser 静默丢非 dict 条目——均 P2。
3. **签名一致性**：逐函数 grep 调用方；`check_linguistic_drift_trigger`、`establish_baseline`、`count_words`/`tokenize`/`count_punctuation`（src 内）为无生产调用方（死导出/对外 API）。
4. **序列化安全**：全 Z6 无 pickle/multiprocessing/subprocess（grep 0 命中）；trace 用 JSON + sha256 链；`model_dump_json`↔`canonical_payload` 经 pydantic 同源 datetime 序列化自洽（test_event.py 确定性用例通过）。
