### F641 | records `_values_equal` 布尔比较孔：YAML 布尔 `true` 与 md 表 `"true"` 比较 → 假 drift（block ship） | 边界/比较缺陷 | P2

- 证据：`src/shenbi/records/drift.py:57-69`（`_values_equal`：`str(yaml_val) == md_val` 兜底 + `float()` 双端比较）；`:92`（不相等即 drift → write_audit block ship）。
- 根因：数值感知比较只覆盖数值（0.8 vs "0.80"）；对布尔值，`str(True)="True"`（Python 字面量）与 YAML/JSON/markdown 规范小写 `"true"` 不相等，`float("true")` 抛 ValueError 落入 `return False` → **假 drift**。即 YAML 记录含 `state: true`（bool）而派生表写 `"true"`（小写）时，判据 12 误报 drift、block ship。
- 验证命令+输出：
  ```
  _values_equal(True, 'true')   -> False   # 假 drift
  _values_equal(True, 'True')   -> True    # 仅 Python 字面量巧合通过
  _values_equal(1,   'true')    -> False
  detect_cross_section_drift([{'id':'h','state': True}],
                             {'h': {'id':'h','state':'true'}})
  -> ["drift: id=h key=state md='true' != YAML=True"]   # 假阳性
  ```
- 影响：当前 fixture（state: PLANTED 等字符串）与 ch-025 快照不触发 → 潜伏；但 hook YAML 若出现布尔字段（如 `core_hook: true`——虽然不在 md 表列中），或未来格式将状态写为布尔，即产生假 drift 阻断 ship。F603（方向）/F616（非 dict）均未覆盖此比较语义孔。
- 建议方向：`_values_equal` 增加布尔分支（`bool(yaml_val) == (md_val.strip().lower() in ("true", "1"))`）或将比较统一为规范化字符串（YAML/JSON 小写）；补单测（True vs "true" 不误报、False vs "false" 不误报）。
