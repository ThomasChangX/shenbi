### F267 | cli.py 只取 argv[4] 作 prompt：未加引号的多词 prompt 静默截断（argv[5:] 丢弃）→ codex 收到残缺指令 | 漏报（CLI 协议边界，F226 机制外的新触发面） | M

- 证据: `src/shenbi/dispatcher/cli.py:28`（`prompt = sys.argv[4] if len(sys.argv) > 4 else ""`——只取第 5 个 argv，argv[5:] 静默丢弃）；`src/shenbi/dispatcher/modes/codex.py:53-54`（空 prompt raise，但**非空残缺** prompt 直接放行）；`docs/getting-started/first-novel.md:41`（文档化调用带引号 `"Build the world"`，引号路径安全）
- 根因: F226 覆盖"缺参 → 空 prompt → SubAgentProtocolError"（loud）；本条是**有参但未加引号**的形态——用户执行 `shenbi-dispatch shenbi-worldbuilding generative <rd> Build the world`（shell 拆成 6 个 argv）时，prompt 静默取为 `"Build"`，`"the"`/`"world"` 被丢弃，codex agent 以残缺指令执行且**无任何 WARN/usage 提示**——与 G4 CLI 的 `sys.argv[2:]` 拼接式解析（gates/cli.py）不同，shenbi-dispatch 是单参数取用。
- 验证命令: 代码级（`cli.py:28` 无 `" ".join(sys.argv[4:])`、无 `len(sys.argv) > 5` 检测）；`grep -n "argv\[4\]\|argv\[5\]\|join(sys.argv" src/shenbi/dispatcher/cli.py` → 仅 :28 一处，无多余参数检测
- 建议方向: `prompt = " ".join(sys.argv[4:])`（与 shell 调用直觉一致）或 `if len(sys.argv) > 5: log.warning("prompt_extra_args_dropped", ...)` 明示截断；补多词 prompt 测试
- 影响注记: 文档化路径（first-novel.md:41 带引号）不受影响；触发需用户未加引号——正常使用中英文 prompt 的常见疏漏，故 M 而非 P2
