### F654 | compute_drift `_try_float` docstring 承诺"非有限数值返回 None"，实际 nan/inf/1e999 透传 → 趋势表出现 nan 单元格时序列被静默污染（smooth 全 nan、σ 统计全 nan、单调 run 中断） | 边界/文档↔代码漂移 | P2

- 证据：`src/shenbi/skill_utils/drift_detection/compute_drift.py:217-222`（`_try_float` docstring "Return ``float(text)``, or None if not a finite numeric value."；实现 `return float(text)`，仅捕获 TypeError/ValueError，无 finiteness 检查）；`parse_trend` :205-208（`score = _try_float(...)`，None 才跳过 → nan/inf 被当作合法分数收入序列）。

- 验证命令+输出：
