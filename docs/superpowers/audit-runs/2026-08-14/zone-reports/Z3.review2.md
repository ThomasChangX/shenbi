## 三、F325 反证（误报，P1 裁定撤回）

  2. 原因：4 个 group skill 的 contract `writes:` 声明旧式路径（`shenbi-review-group-factual` → `['audits/chapter-N-continuity.md','audits/chapter-N-world-rules.md','audits/chapter-N-pacing.md']` 等，uv run 实证）；`_build_skill_prompt`（dispatch_helper.py:653-658）按 contract 生成 "Files to create" 清单，LLM 输出与 `_write_parsed_outputs` 均落盘到 contract 路径；`ReviewTask.output_path`（group-*.md）只是 `cs.audit_results["audit_reports"]` 的追踪标签，从不传进 dispatch_skill、从不写盘；

  4. 真实 BLOCKING 判定链：`collect_audit_issues`（revision_router.py:199-206）的 `_SEVERITY_BLOCKING_RE` 要求字面 "BLOCKING"（`**BLOCKING**` 或 `严重度...BLOCKING\b`）→ 文件必含裸子串 "BLOCKING" → `_any_audit_has_findings`（:1797 `"BLOCKING" in text`）必为 True → step 16 revision 执行。**"BLOCKING 路由后 revision 被跳过"不成立**；
