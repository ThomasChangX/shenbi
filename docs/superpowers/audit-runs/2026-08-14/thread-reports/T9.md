## 二、findings

### T9-01 · [P1] lint_status_strings 对"词表外发明值"全盲：6+ 站点在 status/state 键上发射 `STATUS_STRING_LITERALS` 之外的状态值，CI/预提交门禁全绿

- **证据**（AST 实证：status/state/classification 键上、值 ∉ `STATUS_STRING_LITERALS` 的字符串字面量）：
  - `gates/g4/chapter_revision.py:97` — `"status": GateStatus.PASS if not issues else "HARD_FAIL"`（**GateStatus 域发明值**；docstring :38 与 tests/unit/gates/g4/test_chapter_revision.py:112-179 已把它当契约值断言）
  - `pipeline/cli.py:836` — `cmd_rollback` 信封 `"status": "not_implemented"`（**CommandStatus 域发明值**；同文件其余 11 处 status 键均用 `CommandStatus.*`）
  - `pipeline/truth_embed.py:247` — `"status": CommandStatus.OK if ok else "degraded"`（F3B1 同站点，本 finding 补 **lint 盲区**面）
  - `pipeline/hook_planting.py:188` — `"state": "PLANTED"`（HookState 域；`contracts/schemas/hooks.py:19` 已有枚举但未 import）
  - `trace/materialize.py:28`、`dispatcher/modes/codex.py:44` — progress 域 `"status": "pending"/"done"`
- **机制**：`_is_status_value` 要求 `s in STATUS_STRING_LITERALS`（白名单）。D3 规则要防的正是"第二词表进入代码库"，而白名单逻辑把**不在词表里的新值**全部放行——第二词表不是被拦住，而是**因为不在白名单而畅通无阻**。当前全树 0 违规、exit 0，`ci.yml:52`、`.pre-commit-config.yaml:59`、`pre-push-check.sh:26`、`justfile:15/45` 四处接线全部空转。
- **影响**：D3「no bare status string-literals outside status.py」对最有危害的站点（发明值）零效力；`HARD_FAIL` 已成为门禁/测试依赖的隐式契约值，无类型、无单一信源。
- **建议**：检测反转为"status/state/classification 键上的**任意字符串字面量**必须命中 `STATUS_STRING_LITERALS` **或**显式域白名单/枚举成员"；`HARD_FAIL`/`not_implemented` 入 `status.py` 枚举（或改枚举成员发射）。

### T9-02 · [P2] "s" 键通道 186 处裸 GateStatus 字面量完全绕 lint；同键双轨（g4 枚举成员 vs 其余裸串）

- **证据**：`grep -rE '"s": *"(PASS|FAIL|SKIP|WARN|UNIMPLEMENTED)"' src/shenbi/gates/*.py` = **186 处**（g0:38、g2:33、g1:22、g6:19、g3:19、g7:17…）。lint docstring 明示把 `{"id": "G3.1", "s": "PASS"}` 作为"false positive"豁免（STATUS_KEYS 无 "s"）。
- **同键双轨**：`gates/g4/generic.py:196` 用 `{"id": check_id, "s": GateStatus.FAIL if … else GateStatus.WARN}`（枚举成员）；`g0.py:200`、`g1.py:200`、`g2.py`、`g3.py`、`g5.py`、`g6.py`、`g7.py` 同键全裸字符串。消费端 `g7.py:265` `check.get("s") == "WARN"` 裸比较。
- **影响**：D3 的实际覆盖不足 1/5——"status"键枚举发射 49 处 vs "s" 键裸量 186 处。check-item 是门禁间共享的契约数据（G5.5/G7.14/G7.15 读取），其状态值零类型保护；"s" 键是 GateStatus 词表的**主发射通道**，lint 却完全不看它。
- **建议**：将 "s" 纳入 STATUS_KEYS（或 check-item 定义统一改 GateStatus 成员，g4/generic.py 已示范）；至少把 `GateStatus` 值改为从单一常量表引用。

### T9-03 · [P2] ChapterState.status 无类型字段 3 拼写漂移（pending/complete/settling_failed）；progress.json 同键承载第二套词表（pending/done/skip）
