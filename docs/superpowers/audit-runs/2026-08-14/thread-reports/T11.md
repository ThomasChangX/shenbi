## 5. 突变测试 mutmut

### 5.1 仓库配置实测：结构性不可运行（T1101，P2）

沙箱 `/tmp/t11-mutmut`（symlink src/tests + 副本 pyproject，`.venv` 指向仓库 venv），按仓库 `[tool.mutmut]` 配置（`paths_to_mutate` 3 文件 + `pytest_add_cli_args_test_selection=["tests/unit/"]`）运行：

```
uv run mutmut run --use-cache
→ BadTestExecutionCommandsException: Failed to run pytest ...
→ ImportError while loading conftest 'mutants/tests/unit/conftest.py':
     from shenbi.dispatcher import executor → ModuleNotFoundError: No module named 'shenbi.dispatcher'
```

**根因**：mutmut 3.6 `copy_src_dir()` 只把被突变文件（3 个）拷入 `mutants/src/shenbi/`，包树不完整；`setup_source_paths()` 又把 `mutants/src` 插入 sys.path[0] 并**删除原 src**——于是 `tests/unit/conftest.py:10` 的 `from shenbi.dispatcher import executor` 解析到残缺副本而失败。**任何导入非突变子模块的测试都会炸，与"test_g4_fail_no_marker 子进程隔离"无关**——`mutation-score.txt` 中对基线失败原因的记录（归因 PR-19 子进程测试脆弱性）**归因错误**；真实阻塞是结构性、可复现的。

### 5.2 修复后实际跑通（T1103，P2 — 分数证据）

在沙箱 pyproject 加 `also_copy = ["src"]`（copytree `dirs_exist_ok=True` 补全包树），并把测试选择收窄为直接测试文件（`test_exceptions.py` / `test_logging.py` / `test_shared.py`，deselect 4 个 `uv run` 子进程日志测试——子进程在沙箱 cwd 下 `uv run` 会重建项目而失败）：

```
mutmut run --max-children 4
→ 3 files mutated, 0 ignored
→ 366/366  🎉 218 killed  🫥 13 no-tests  ⏰ 0  🤔 0  🙁 135 survived  🔇 0  🧙 0
```

**按模块（解析 mutants/*.meta）**：

| 模块 | mutants | killed | survived | no-tests | score |
|---|---|---|---|---|---|
| exceptions.py | 56 | 23 | 33 | 0 | **41.1%** |
| logging.py | 29 | 17 | 12 | 0 | **58.6%** |
| gates/shared.py | 281 | 178 | 90 | 13 | **63.3%** |
| **聚合** | **366** | **218** | **135** | **13** | **59.6%**（剔除 no-tests 61.8%） |

- 存活集中：exceptions 的 `__init__`/`to_dict`/`__str__` 属性突变（33/56 存活）——异常序列化面几乎无测试钉住。
- 目标对照（mutation-score.txt）：P-2 60%、P-3 80% → 实测 59.6%（**下界**：测试选择收窄 + 13 no-tests），低于 P-3 目标且几乎压线 P-2。
- 附注：运行中 mutmut 3.6.0 对 `paths_to_mutate` 报弃用告警（应改 `source_paths`）→ 并入 T1101/T1104。

### 5.3 结论

- **T1101（P2）**：仓库 `[tool.mutmut]` 配置结构性不可运行（残缺 mutant 树）；`mutation-score.txt` 对该失败的归因错误（非子进程测试，是包树复制缺陷）。修复建议：`also_copy=["src"]` 或 `source_paths` 指向包目录。
- **T1102（P2）**：基线文件无分数 + `just mutate-check` 恒 exit 2（死工具）。
- **T1103（P2）**：实测下界分数 59.6%（exceptions 41.1% 最弱），未达宣称 P-3 80%；无 CI 强制。
- **T1104（M）**：`paths_to_mutate` 弃用配置键（mutmut 3.6 告警，应 `source_paths`）。
