    G4 门判别力基线（恒真登记）· spec #116

    登记分母 = src/shenbi/gates/g4/chapter_drafting.py 单文件 AST 单源（check 行 dict id ∪ mf 首常量 id，经别名表回射 canonical）∪ 扫描不可见的显式补充面。 check-id 对账由 tools/lint_gate_power_baseline.py 执行（进 just lint）： 行缺/多、分类值域外、非 discriminating 缺证据、registry↔AST 漂移均红；本表 与 docs/framework/invariants.md 分工——彼表管不变量维度覆盖，本表管判别力。

    口径定义（附录 A 列锚，r2/M3；M3 用词统一——列值与 registry _caliber() 输出一致）

    • state-free：不读 truth oracle 可机检（读 memo/plans 声明属此列）；
    • truth（附录 A 原文作「truth 依赖」，列值统一取 registry _caliber() 形）： 回放历史章对当前 truth 有伪 FAIL 面的对账类（handoff/balance/counter 族； hook_type_rotation 读 plans 历史亦入此列）。WARN-only 行（provenance_anchor） 无伪 FAIL 面、伪 WARN 面如实——口径按「是否读 truth oracle」判，不按 FAIL/WARN 判，仍入此列。

    分类语义（值域五值，闭合）

    值 语义
    unclassified 尚未裁定（初始态；证据列允许填红测链接供裁定参考）
    floor-untested 裁定为「floor 有效但本语料从未触发下界」——0 点火可接受
    decorative 裁定为装饰性/恒真——判别力缺失，须给整改或保留依据
    discriminating 裁定为有判别力——真语料开火或红测可捕获
    retired 已退役（连同年发射面移除的检查）

    分类必须人工裁定：判别力 ≠ 正确性——0 点火可能是 floor 有效（从未需要）， 也可能是门已坏；仪表与 lint 均不得自动断言分类，lint 只强制登记在册与义务 可见（非 discriminating 行证据列非空）。
